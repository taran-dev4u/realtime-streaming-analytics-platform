Distributed real-time streaming data and analytics platform processing high-throughput events using **Apache Kafka**, **Spark Streaming**, **FastAPI**, and **Prometheus / Grafana** observability.

---

## 🎯 Architecture & Capabilities

- **High-Throughput Message Ingestion:** Kafka multi-partition event streaming supporting 2,500+ messages per second.
- **Spark Structured Streaming:** Sub-second sliding window aggregations, anomaly detection, and stateful stream processing.
- **FastAPI Real-Time Gateway:** Asynchronous query endpoints serving live aggregated KPIs with low latency (<15ms).
- **Comprehensive Test Coverage:** 100% deterministic unit and integration test suite.
